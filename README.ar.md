## التركيب في ثلاث خطوات

1. **نزّل [Windhawk](https://windhawk.net) وثبّته.** برنامج Windhawk هو الذي يشغّل
   المودات مثل هذا. ثبّته مرة واحدة وهو يتولّى الباقي.
2. **نزّل ملف المود:**
   **[taskbar-network-lounge.wh.cpp](https://github.com/cracken7/TaskbarNetworkLounge/releases/latest/download/taskbar-network-lounge.wh.cpp)**
3. **في Windhawk** اضغط *Create a new mod*، ثم حدّد كل ما في المحرّر، والصق الملف
   فوقه، ثم اضغط *Compile mod*.

سيظهر المؤشر على شريط المهام بعد ثوانٍ. ولو واجهت أي مشكلة، أو أردت الشرح خطوة
بخطوة، اقرأ **[INSTALL.md](INSTALL.md)**.

## ما تراه أمامك

الودجت مستطيل صغير واحد، مقسوم إلى نصفين بخط رفيع.

| النصف | العنوان | ما يعرضه |
| --- | --- | --- |
| اليسار | **SPEED** | سرعة التحميل والرفع **في هذه اللحظة** |
| اليمين | **TOTAL** | إجمالي ما نزّلته وما رفعته |

وفي النصفين، السطر الأعلى للتحميل والسطر الأسفل للرفع:

- **سهم أزرق متّجه لأسفل** = تحميل
- **سهم أخضر متّجه لأعلى** = رفع

وكل رقم مكتوبة وحدته بجانبه، فلا لبس أبدًا في ما تقرأه.

### أربع طرق للتعامل معه

**مرِّر الماوس** فوق الودجت فيظهر تلميح بنفس الأرقام مع اسم كرت الشبكة الذي يُقاس.

**اضغط بالزر الأيسر** لتفتح لوحة التفاصيل — بطاقة زجاجية فيها كل ما يعرفه المود:
أي كرت يراقبه، وهل هذا الكرت متصل، وعنوانه، والسرعات الحالية، والإجماليات
المتراكمة، وزر يصفّر الإجماليات.

![لوحة التفاصيل](docs/panel.png)

**اضغط بالزر الأوسط** (ضغط العجلة) للتنقّل بين ما يعرضه الودجت: النصفان معًا ←
السرعة فقط ← الترافيك فقط ← النصفان.

**اضغط بالزر الأيمن** لتظهر قائمة:

| عنصر القائمة | ما يفعله |
| --- | --- |
| Refresh | يأخذ قراءة جديدة فورًا |
| Show both / Show speed only / Show traffic only | تختار أي جانب يعرضه الودجت |
| Show SPEED caption / Show TOTAL caption | تُشغّل أو تُطفئ العنوان الصغير فوق كل نصف |
| Show arrows | تُخفي الأسهم كليًّا وتُبقي الأرقام فقط |
| Reset download / upload / both | يصفّر الإجماليات |
| Reset divider position | يرجع الخط الفاصل إلى المنتصف |
| Open Network Settings | يفتح صفحة إعدادات الشبكة في ويندوز |
| Windhawk Settings | يفتح إعدادات هذا المود |
| Hide widget | يخفي المؤشر (وترجعه من *يبدأ مُفعّلًا* في الإعدادات) |

وكل ما تختاره من القائمة يُحفَظ ويصمد بعد إعادة التشغيل.

## سبب وجود هذا المود: مشكلة الـVPN

هذه هي الحاجة الوحيدة التي تميّزه عن باقي مؤشرات الشبكة، وتستحق دقيقتين.

**المشكلة.** عند تشغيل VPN ينشئ ويندوز كرت شبكة ثانيًا — كرتًا وهميًّا. ومن تلك
اللحظة تمرّ بياناتك عبر **كرتين** لا كرت واحد:

1. عبر **كرت الـVPN**، الذي يرى بياناتك قبل تشفيرها، و
2. عبر **كرت الإيثرنت أو الواي فاي الحقيقي**، الذي يحمل النسخة المشفّرة إلى
   الإنترنت.

إنها نفس البيانات، تُعَدّ عند نقطتين مختلفتين. ومعظم مؤشرات الشبكة تجمع كل كرت
تجده، فتحميل حجمه 1 جيجا يظهر **2 جيجا**. وهذا ليس خطأ تقريب، هذا ضعف العدد.

**الحل.** يسأل هذا المود ويندوز سؤالًا أدقّ: *أي كرت واحد تستخدمه فعلًا للوصول إلى
الإنترنت الآن؟* ثم يقيس هذا الكرت وحده، لا غيره. عمليًّا:

- شغّل VPN ← يتابعه المؤشر.
- أوقِف VPN ← يعود إلى الإيثرنت أو الواي فاي.
- ولا يُحسَب أي شيء مرتين، مهما كان ما تستخدمه.

**والإجماليات تبقى ذات معنى.** 4 جيجا نزّلتها عبر الإيثرنت لا تقول شيئًا عن الـVPN
الذي اتصلت به الآن، لذا تبدأ الإجماليات من الصفر افتراضيًّا عند كل تغيّر في مصدر
الإنترنت. ولو أردت إجماليًّا واحدًا يمتد عبر كل الاتصالات، أوقِف إعداد *تصفير
العدادات عند تغيّر مصدر الإنترنت*.

والانقطاع القصير لا يُعامَل كتغيّر مصدر. نزع الكابل ثانيتين أو نفق لم يكتمل
اتصاله لن يمسح إجمالياتك.

**ولو أردت الاختيار بنفسك** يمكنك: قياس الإيثرنت وحده، أو الواي فاي وحده، أو كل
الكروت معًا، أو كرت محدد تكتب اسمه.

## ما يمكنه فعله

### اعرض السرعة أو الترافيك أو الاثنين

يمكن للودجت عرض النصفين جنبًا إلى جنب، أو السرعات الحيّة وحدها، أو إجماليات
الترافيك وحدها. بدّل من قائمة الزر الأيمن، أو من إعداد *عرض الترافيك أو السبيد*،
أو بضغطة وسطى واحدة. واختيارك يُحفَظ، والتخطيط يتكيّف: النصف الوحيد يملأ العرض
بدل أن يبقى فراغ.

### الأرقام مقيسة لا مقدَّرة

يسأل المود ويندوز عن عدد البايتات التي نقلها الكرت، ثم ينتظر، ثم يسأل مرة ثانية،
ويقسم الفرق على الزمن الذي مضى بدقّة. هذه هي الطريقة كلها. لا يقرأ مخرجات
`ipconfig` أو `netstat` أو PowerShell أبدًا، ولا يخمّن.

وبالمقارنة مع عدّادات ويندوز نفسها على مدى 22 ثانية، طابقتها النتيجة بفرق لا يزيد
عن **0.06%**.

### البايت والبِت لا يخلطهما أحد

الوحدتان تتشابهان في الاسم وتختلفان تمامًا في المعنى:

- **`MB/s`** = ميجابايت في الثانية — الوحدة التي يستخدمها مستكشف الملفات ومديرو التحميل.
- **`Mbps`** = ميجابِت في الثانية — الوحدة التي تروّج بها شركات الإنترنت.

وفي البايت 8 بِتات، فنفس الاتصال يظهر أعلى 8 أضعاف بـ`Mbps`. والخلط بينهما هو
أشهر سبب لقراءة أرقام الشبكة قراءة خاطئة، لذا تطبع الوحدة دائمًا بجانب الرقم،
والاختيار لك.

### أنت الذي تقرّر شكله

| ما يمكنك تغييره | الاختيارات |
| --- | --- |
| **شكل السهم** | اثنان وعشرون شكلًا — صلب، دائري الأطراف، شيفرون، مثلث، شيفرون مزدوج وثلاثي، مفرّغ، خيطي، كتلي، رأس سهم فقط، داخل دائرة أو حلقة أو مربع دائري، متلاشٍ، متقطّع، بخطّافات، إبرة، بنقطة، بريش، بطبقتين، سهم داخل درج، وسهم بعلامة زائد (+) — أو أخفِ الأسهم كليًّا |
| **حجم السهم** | كنسبة من حجم النص؛ ولن يكبر أبدًا أكثر من المساحة المتاحة |
| **الخط** | أي خط مثبت في جهازك (فارغ = Segoe UI)، خمسة أوزان (عريض، أسود، نصف عريض، عادي، مائل)، وأي حجم |
| **لون لكل اتجاه** | حدّد لونًا خاصًا للتحميل وآخر للرفع — السهم والأرقام معًا — أو اترك الأزرق/الأخضر الافتراضي |
| **عنوانا SPEED / TOTAL** | أظهرهما أو أحدهما أو أخفِهما — من الإعدادات أو من قائمة الزر الأيمن |
| **الخط الفاصل** | **اسحبه بالماوس** لتوسّع أحد الجانبين، أو خفّفه، أو أخفِه كليًّا |
| **مقاس الودجت** | العرض والارتفاع، ومكانه على طول شريط المهام |
| **مقاس لوحة التفاصيل** | العرض وحدّ أدنى للارتفاع — اللوحة تكبر وحدها لو احتاج محتواها مساحة |
| **التخطيط** | السرعات والإجماليات جنبًا إلى جنب، أو السرعات وحدها في سطرين، أو كل شيء في سطر واحد |

![أشكال الأسهم](docs/arrow-styles.png)

وبخصوص سحب الخط الفاصل: امسكه وحرّكه يمينًا أو شمالًا، و**الخط وحده هو الذي
يتحرك**. الأرقام تبقى في مكانها تمامًا — لا شيء ينزاح أو يعيد ترتيب نفسه.
وموضعك يُحفَظ، وعنصر *Reset divider position* في قائمة الزر الأيمن يعيده للمنتصف.

### لا يثقل على جهازك

يأخذ قراءة واحدة كل ثانية (والمدة قابلة للتغيير) على خيط في الخلفية، ولا يعيد
الرسم إلا عند تغيّر رقم ظاهر فعلًا على الشاشة. وبالقياس على جهاز عادي:
**0.3–0.5% من نواة معالج واحدة**، وحوالي **30 ميجابايت** من الذاكرة، وبلا أي تسريب
مقابض بعد 1500 عملية رسم.

### مظهره أصلي من ويندوز

زجاج أكريليك حقيقي، وحواف دائرية، ويتبع الثيم الفاتح والغامق عندك. لا نافذة
أوامر، ولا محرّك متصفح، ولا .NET أو Python — مكوّن C++ أصلي واحد.

وحدّة النص ضُبطت بقياس البكسلات لا بالنظر بالصور، وهذا مهمّ عند هذا الحجم: النص
الصغير الفاتح فوق خلفية ضبابية هو بالضبط الموضع الذي تخطئ فيه عادةً مقاومة
التهتّك.

### يتكلّم العربية

كل اسم إعداد، وكل وصف، وكل خيار في القوائم مترجم. ويعرض Windhawk العربية
تلقائيًّا حين تكون لغة عرض ويندوز عربية — بلا أي تشغيل.

## المتطلبات

- **ويندوز 11** للحواف الدائرية والتأثير الزجاجي. ويعمل على **ويندوز 10** أيضًا
  بحواف قائمة.
- **[Windhawk](https://windhawk.net)** مثبّتًا.
- لو كان زر **Widgets** في ويندوز يشغل نفس المكان ويغطّي المؤشر، فأوقِف Widgets من
  إعدادات شريط المهام، أو حرّك المؤشر بإعداد **الإزاحة الأفقية**.

---

## حدود معروفة

مكتوبة بصراحتك حتى لا يفاجئك شيء:

- يعمل الودجت في عملية مساعدة منفصلة. وهذا مقصود — خلل في المود لا يسقط سطح
  المكتب معه. والأثر الظاهر: سترى سطرًا ثانيًا باسم *Windows Explorer* في مدير
  المهام، وأي مود آخر يستهدف Explorer سيُحمَّل في تلك العملية أيضًا.
- يرتبط بشريط المهام **الرئيسي**. أشرطة المهام الثانوية على الشاشات الأخرى خيار
  احتياطي فقط.
- الأشرطة الرأسية معالَجة في الكود لكنها لم تُختبَر إلا فعليًّا (offline).
- ARM64 لم يُختبَر.
- *Hide widget* لا رجوع له بأيقونة في علبة النظام؛ استخدم *يبدأ مُفعّلًا* من
  الإعدادات.
- قد تختلف قراءة واحدة عن مدير المهام بنسبة قليلة لأن كلًّا منهما يأخذ لقطته في
  لحظة مختلفة قليلًا. وبالمعدل على مدى ثانية يتطابقان.

### البنية

```
src/p1_header.inc      البيانات الوصفية، @include explorer.exe، إعدادات YAML (عربي + إنجليزي)
src/p2_core.inc        الترويسات، ModSettings، المتغيرات العامة وقوائم الضغط
src/p3_settings.inc    قراءة الإعدادات وضبط الحدود، تنسيق الوحدات، التخزين
src/p4_network.inc     عيّنات GetIfTable2، ترشيح الكروت واختيارها،
                       اكتشاف تغيّر المصدر وتصفير العدادات
src/p5_render.inc      رسم GDI+: 22 شكل سهم، النص الحاد، الودجت ولوحة التفاصيل
src/p6_window.inc      هندسة شريط المهام، منطقة الخط الفاصل، التلميح، القائمة
src/p7_lifecycle.inc   إجراء النافذة (ومنها سحب الخط)، Wh_ModInit/AfterInit
```

`build.sh` يلصق هذه الأجزاء في ملف `taskbar-network-lounge.wh.cpp` واحد كما يطلب
Windhawk. و`install.py` يكتبه في Windhawk ويعيد تشغيل المحرّك.
و`tools/arrow_showcase.cpp` يولّد صورة `docs/arrow-styles.png` من كود رسم الأسهم
الحقيقي في المود، فلا تبتعد الصورة أبدًا عمّا يرسمه المود.

### الأوامر

```bash
bash build.sh              # توليد ملف .wh.cpp وتركيب DLL للاختبار
bash tests/run_all.sh      # كل المجموعات الاختبارية الثمانية
python install.py          # التثبيت في Windhawk وإعادة تشغيل المحرّك
python tools/setopt.py --show
```

### القياسات

إيثرنت (Realtek PCIe GbE)، 1920 × 1080 عند 100%، ويندوز 11، Windhawk 1.7.3.

| | |
| --- | --- |
| الدقة مقابل عدّادات ويندوز | 1.0006 تحميل / 1.0008 رفع على مدى 22 ثانية (0.06%) |
| المعالج | 0.09–0.14 ثانية لكل 30 ثانية ≈ 0.3–0.5% من نواة واحدة |
| الذاكرة | 27–31 ميجابايت، انحراف ±60 كيلوبايت |
| مقابض GDI / USER | +1 / +2 بعد 1500 عملية رسم |
| حدّة النص | 57.2% من بكسلات الحروف مشبعة بالكامل، وصفر تشوّش لوني |

ضُبط رسم النص بالقياس لا بالنظر: ClearType فوق الأكريليك أنتج 112 بكسل مشوّشة،
لذا يستخدم المود تدرّج رمادي `AntiAliasGridFit` مع ظلّ تباين 1 بكسل، وتنسيق
`GenericTypographic` — لأن التنسيق الافتراضي يضيف حوالي 1/6 em حشوًا جانبيًا كان
يقطع `12.4 MB/s`.
