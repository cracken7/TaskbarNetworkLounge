## التركيب

1. نزّل [Windhawk](https://windhawk.net) وثبّته — هو البرنامج الذي يشغّل هذا المود.
2. نزّل ملف **[taskbar-network-lounge.wh.cpp](https://github.com/cracken7/TaskbarNetworkLounge/releases/latest/download/taskbar-network-lounge.wh.cpp)**.
3. في Windhawk: **Create a new mod** ← حدّد الكل ← الصق الملف ← **Compile mod**.

يظهر المؤشر على شريط المهام في ثوانٍ. الشرح خطوة بخطوة وحلّ المشاكل:
**[INSTALL.md](INSTALL.md)**.

| | |
| --- | --- |
| **سرعة حيّة** | التحميل والرفع، تُقرأ من عدّادات كرت الشبكة الحقيقية (`GetIfTable2`) وتُقسَم على الزمن المقيس فعليًّا (`QueryPerformanceCounter`)، بدون قراءة مخرجات `ipconfig` أو `netstat` أو PowerShell. |

| **خط فاصل يُسحَب** | امسك الخط بين عمودَي SPEED و TOTAL وحرّكه — الخط وحده يتحرك والكتابة تبقى في مكانها. |
| **لوحة تفاصيل** | بضغطة واحدة: الكرت والحالة وعنوان IPv4 والسرعات والإجماليات وزر تصفير. وتلميح عند المرور بالماوس، وقائمة عند كليك يمين. |
| **بايت أم بِت** | `MB/s` تعني ميجابايت في الثانية و`Mbps` تعني ميجابِت في الثانية، والوحدة مكتوبة دائمًا بجانب الرقم. |
| **واجهة بلغتين** | كل اسم إعداد ووصف وخيار مترجم للعربية، وWindhawk يبدّل تلقائيًّا حسب لغة واجهة ويندوز. |
| **خفيف** | نداء واحد لكل دورة على خيط منفصل، وإعادة رسم فقط عند تغيّر الأرقام. 0.3–0.5% من نواة واحدة، و27–31 ميجابايت، وبلا تسريب مقابض. |
| **أصلي** | ملف DLL واحد بلغة C++ داخل `explorer.exe`. بلا نافذة كونسول، وبلا WinForms/WPF، وبلا Electron، وبلا متصفح، وبلا Python. |

## لماذا احتاجت حالة الـVPN إصلاحًا

أثناء تشغيل VPN يحمل كرت النفق والكرت الفيزيائي نفس البيانات: النفق يرى المحتوى
المفتوح والكرت يرى النسخة المشفَّرة. وجمعهما يجعل تحميل 1 جيجا يظهر 2 جيجا — وهذا
هو الخطأ الذي بُني المود لتجنّبه.

الوضع التلقائي يحدّد الكرت الحامل لمسار الإنترنت الافتراضي (`GetBestInterfaceEx`)
بين **كل** الكروت الحقيقية، ثم يحسب **كرتًا واحدًا فقط**. فيُتابَع الـVPN وهو حامل
الإنترنت ويُترَك حين لا يكون كذلك. ولأن رقمًا متراكمًا من اتصال آخر لا يصف شيئًا،
تتصفّر الإجماليات عند تغيّر المصدر — مع عدم اعتبار الانقطاع اللحظي (فصل الإيثرنت
قبل أن يعمل النفق) تغييرًا للمصدر.

## بنية الكود

```
src/p1_header.inc      البيانات الوصفية و@include explorer.exe وYAML الإعدادات (إنجليزي + عربي)
src/p2_core.inc        الترويسات وModSettings والمتغيرات الذرّية ومعرّفات القائمة
src/p3_settings.inc    قراءة الإعدادات وتقييدها، وتنسيق الوحدات، والحفظ الدائم
src/p4_network.inc     أخذ القياسات بـGetIfTable2، وفلترة الكروت واختيارها،
                       وكشف تغيّر المصدر وتصفير العدادات
src/p5_render.inc      الرسم بـGDI+: الأسهم والنص الحادّ والودجت ولوحة التفاصيل
src/p6_window.inc      هندسة شريط المهام، واختبار إصابة الخط الفاصل، والتلميح، والقائمة
src/p7_lifecycle.inc   معالج النوافذ (وفيه سحب الخط) وWh_ModInit/AfterInit
```

يدمج `build.sh` هذه الملفات في ملف `taskbar-network-lounge.wh.cpp` الواحد الذي
يطلبه Windhawk، ويكتبه `install.py` داخل Windhawk ويعيد تشغيل محرّكه.

## البناء والاختبار

```bash
bash build.sh              # إعادة توليد ملف wh.cpp وبناء DLL للاختبار
bash tests/run_all.sh      # كل مجموعات الاختبار الثماني
python install.py          # التثبيت في Windhawk وإعادة تشغيل المحرّك
python tools/setopt.py --show
```

## القياسات

إيثرنت (Realtek PCIe GbE)، شاشة 1920 × 1080 بتحجيم 100%، ويندوز 11، Windhawk 1.7.3.

| | |
| --- | --- |
| الدقة مقابل عدّادات ويندوز | 1.0006 تحميل / 1.0008 رفع خلال 22 ثانية (فرق 0.06%) |
| المعالج | 0.09–0.14 ثانية لكل 30 ثانية ≈ 0.3–0.5% من نواة واحدة |
| الذاكرة | 27–31 ميجابايت، بانحراف ±60 كيلوبايت |
| مقابض GDI / USER | +1 / +2 بعد 1500 دورة رسم |
| حِدّة النص | 57.2% من بكسلات الحروف بكامل الشدّة، وبلا تلوّن حواف |

ضُبط رسم النص بالقياس لا بالنظر: ClearType فوق الأكريليك أنتج 112 بكسلًا ملوّن
الحواف، فاستُخدم `AntiAliasGridFit` الرمادي مع ظلّ تباين بمقدار بكسل واحد، ومع
`GenericTypographic` — لأن التنسيق الافتراضي يضيف حشوًا جانبيًّا بمقدار سُدس em كان
يقطع `12.4 MB/s`.

## حدود معروفة

- يعمل الودجت في عملية `explorer.exe` مساعدة مخصّصة، فيظهر في مدير المهام سطر ثانٍ
  باسم "Windows Explorer"، وأي مود آخر يستهدف `explorer.exe` يُحمَّل في العملية
  المساعدة أيضًا.
- يرتبط بشريط المهام **الأساسي** (`Shell_TrayWnd`)، والأشرطة الثانوية بديل احتياطي فقط.
- شريط المهام الرأسي مُعالَج في الكود لكنه مُختبَر أوفلاين فقط.
- معمارية ARM64 غير مُختبَرة.
- خيار "Hide widget" ليس له أيقونة في منطقة الإشعارات لإرجاعه — أعِد تفعيله من
  Behavior ← Start enabled.
- السرعات تُقاس بالتقطيع الزمني، فقراءة واحدة قد تختلف عن مدير المهام بنسبة قليلة،
  لكن المتوسط خلال ثانية مطابق.
